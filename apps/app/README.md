# Crafton Launcher desktop shell

Tauri application that hosts the Crafton Launcher interface from `apps/app-frontend` and exposes the launcher core from `packages/app-lib` as Tauri commands (`src/api`).

Run it from the repository root:

```bash
SQLX_OFFLINE=true pnpm dev
```

See the [repository README](../../README.md) for requirements and build instructions.
